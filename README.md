# 晨光咖啡機 ☕️

這是一個使用 SwiftUI 製作的入門練習 App。使用者可以選擇飲品、甜度與杯子份量，也可以讓 App 隨機選擇飲品。按下「開始製作」後，畫面會顯示完成圖片和訂單內容。

## 功能

- 選擇美式咖啡、拿鐵或可可
- 選擇無糖、微糖或正常糖
- 選擇小杯、中杯或大杯
- 隨機選擇飲品
- 突顯目前選擇的按鈕
- 顯示完成圖片與飲品資訊
- 尚未選擇飲品時，無法按下「開始製作」

## 使用技術

- Swift
- SwiftUI
- `@State` 儲存畫面狀態
- `VStack`、`HStack` 排列畫面
- `Text`、`Image`、`Button` 建立介面
- `if / else` 判斷選擇結果
- `Int.random(in:)` 隨機選擇飲品
- 基礎 SwiftUI 修飾器，例如 `padding`、`background`、`cornerRadius` 和 `shadow`

## 操作方式

1. 選擇一種飲品，或按下「隨機選擇」。
2. 選擇甜度。
3. 選擇杯子份量。
4. 按下「開始製作」。
5. 查看完成圖片與訂單內容。

## 執行方式

1. 使用 Xcode 開啟專案。
2. 選擇 iPhone 模擬器。
3. 按下 Xcode 上方的執行按鈕，或使用 `Command + R`。

## 專案目的

這個專案用來練習 SwiftUI 最基本的畫面排列、按鈕事件與狀態更新，適合剛開始學習 iOS App 開發的人。
